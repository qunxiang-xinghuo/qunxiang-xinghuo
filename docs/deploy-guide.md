# 🚀 群像·星火 部署指南（大白话版）

> 本文档教你如何把"只有你自己电脑能看到的网站"变成"全世界任何人输入网址就能看到的网站"。

---

| 方案 | 难度 | 速度 | 稳定性 | 适合场景 |
|------|------|------|--------|---------|

- 如果你**现在就要给评委看**，用 **方案A（ngrok）**，5分钟搞定
- 如果你**要长期稳定运行**，用 **方案B（腾讯云+宝塔）**

## 方案A：ngrok（内网穿透）—— 5分钟让全世界访问你的网站

### 大白话解释

你的电脑在"小区"（内网）里，外面的人找不到你。ngrok 就像一个**快递中转站**，它给你一个**公共地址**（比如 `https://abc123.ngrok-free.app`），任何人访问这个地址，ngrok 就把请求转发到你家电脑。

**缺点**：免费版地址每次重启会变，而且8小时后会失效。适合临时演示。

### 操作步骤

#### 第1步：先启动你的网站

```bash
npm run dev
```

看到 `Server ready on http://0.0.0.0:3000` 就说明网站在跑了。

#### 第2步：打开另一个终端窗口，运行 ngrok

```bash
# 方案1：直接运行
npx ngrok http 3000

# 方案2：用我配置好的快捷命令
npm run share
```

#### 第3步：复制公网地址发给队友/评委

运行后你会看到类似这样的输出：

```
Session Status                online
Account                       YourName (Plan: Free)
Version                       3.x.x
Region                        United States (us)
Web Interface                 http://127.0.0.1:4040
Forwarding                    https://abc123-def.ngrok-free.app -> http://localhost:3000
```

**把 `https://abc123-def.ngrok-free.app` 这个地址发给别人**，他们就能访问你的网站了！

> ⚠️ **注意**：
> - 免费版这个地址**8小时后会失效**，需要重新运行
> - 免费版每次重启地址会变（`abc123` 这部分会变）
> - 如果需要固定地址，要花钱买付费版（约 $8/月）

#### 第4步：关闭 ngrok

按 `Ctrl + C` 即可关闭。关闭后外网地址就失效了。

## 方案B：腾讯云轻量服务器 + 宝塔面板 —— 长期稳定部署

### 大白话解释

**服务器** = 你租了腾讯的一台电脑，放在腾讯的机房里，24小时开机，自带公网门牌号（IP地址）。

**宝塔面板** = 这台远程电脑的"遥控器"，不用记那些黑乎乎的命令，点按钮就能装网站、传文件、开数据库。

**部署** = 把你电脑上的网站代码，传到租来的服务器上，让它24小时运行，全世界都能找到。

### 前置条件

1. 你已经买了**腾讯云轻量应用服务器**（推荐 2核4G 配置，约 60元/月）
2. 服务器上已经装了 **宝塔面板**（宝塔官网有安装教程，一行命令搞定）
3. 你有一个**域名**（可选，没有域名就用 IP 地址访问）

### 操作步骤

#### 第1步：在本地准备好代码

先确保你的代码能正常构建：

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，把 NEXTAUTH_URL 改成你的服务器地址：
# NEXTAUTH_URL=http://你的服务器IP:3000
# 或者如果有域名：
# NEXTAUTH_URL=https://你的域名.com

# 3. 生成 Prisma Client
npx prisma generate

# 4. 构建项目
npm run build
```

构建成功后会生成 `.next` 文件夹。

#### 第2步：把代码传到服务器

**方法一：宝塔面板文件管理器（推荐，最简单）**

1. 打开宝塔面板（浏览器输入 `http://你的服务器IP:8888`）
2. 左侧菜单点 **"文件"**
3. 进入 `/www/wwwroot/` 目录
4. 点击 **"上传"** → 选择你电脑上的项目文件夹（或者打包成 zip 上传后解压）

**方法二：Git 克隆（如果你代码在 GitHub 上）**

1. 在宝塔面板里打开 **"终端"**
2. 执行：
```bash
cd /www/wwwroot
git clone https://github.com/qunxiang-xinghuo/qunxiang-xinghuo.git
```

#### 第3步：在服务器上安装 Node.js

1. 宝塔面板左侧 → **"软件商店"**
2. 搜索 **"Node.js"**
3. 安装 **Node.js 20.x 版本**
4. 安装完成后，打开 **"网站"** → **"Node项目"**

#### 第4步：宝塔面板配置 Node 项目

1. 宝塔面板 → **"网站"** → **"Node项目"** → **"添加Node项目"**
2. 填写信息：
   - **项目目录**：`/www/wwwroot/qunxiang-xinghuo`
   - **启动选项**：`命令行启动`
   - **启动命令**：`npm run start`
   - **项目端口**：`3000`
   - **运行用户**：`www`
3. 点击 **"提交"**

宝塔会自动帮你：
- 安装 npm 依赖
- 运行项目
- 设置开机自启

#### 第5步：配置 Nginx 反向代理（让80端口访问你的网站）

现在网站跑在 3000 端口，但别人访问网站默认走 80 端口。需要配置 Nginx 做"转接"。

1. 宝塔面板 → **"网站"** → 添加站点
2. 域名填写你的域名（或服务器 IP）
3. 创建成功后，点网站名旁边的 **"设置"**
4. 选择 **"反向代理"** 标签
5. 点击 **"添加反向代理"**
   - 代理名称：`xinghuo`
   - 目标 URL：`http://127.0.0.1:3000`
   - 发送域名：`$host`
6. 点击 **"保存"**

现在访问你的域名（或服务器IP），就能看到网站了！

#### 第6步：配置域名 + SSL（HTTPS）

如果你有域名，建议配 SSL（网址前面变成 https://，更安全）。

1. 宝塔面板 → **"网站"** → 点你的网站 → **"SSL"** 标签
2. 选择 **"Let's Encrypt"** 免费证书
3. 勾选你的域名 → 点击 **"申请"**
4. 申请成功后，打开 **"强制HTTPS"** 开关

#### 第7步：配置防火墙

1. 腾讯云控制台 → 你的服务器 → **"防火墙"**
2. 添加规则：
   - 端口：`80,443,3000`
   - 协议：`TCP`
   - 来源：`0.0.0.0/0`（允许所有人访问）

#### 第8步：数据库初始化

```bash
# 在宝塔终端里执行
cd /www/wwwroot/qunxiang-xinghuo
npx prisma db push
npx prisma db seed
```

#### 完成！🎉

现在任何人访问你的域名（或服务器IP）都能看到网站了！

## 方案C：Docker 部署（适合会 Docker 的开发者）

如果你的服务器上装了 Docker，可以直接用项目自带的配置：

```bash
# 1. 构建镜像
docker build -t qunxiang-xinghuo .

# 2. 运行容器
docker run -d \
  -p 3000:3000 \
  --name xinghuo \
  --env-file .env \
  -v $(pwd)/dev.db:/app/dev.db \
  qunxiang-xinghuo
```

或者用 docker-compose：

```bash
docker-compose up -d
```

## 🔧 常见问题

### Q1：ngrok 访问很慢怎么办？

ngrok 免费版服务器在美国，国内访问慢。解决方案：
- 花钱买付费版（有亚洲节点）
- 或者直接用**方案B（腾讯云服务器）**，国内速度快

### Q2：宝塔面板提示"端口被占用"？

可能 3000 端口已经被其他程序占用。解决：
1. 宝塔面板 → "安全" → 放行 3000 端口
2. 或者换个端口（比如 3001），同时修改 server.ts 里的端口

### Q3：NextAuth 登录跳转回 localhost？

因为你 `.env` 里的 `NEXTAUTH_URL` 还是 `http://localhost:3000`。要改成你的公网地址：

```
NEXTAUTH_URL=https://你的域名.com
# 或者
NEXTAUTH_URL=http://你的服务器IP:3000
```

改完重新构建并重启服务。

### Q4：网站访问显示 502 Bad Gateway？

说明 Nginx 找不到你的 Node 服务。检查：
1. Node 项目是否真的在运行（宝塔 → Node项目 → 看状态）
2. 反向代理配置的目标 URL 是否正确
3. 端口是否被防火墙拦截

### Q5：怎么更新网站代码？

**ngrok 方案**：代码改了直接刷新浏览器就行，不需要重新部署

**服务器方案**：
1. 本地修改代码 → `git push` 到 GitHub
2. 服务器上：`git pull` → `npm install` → `npm run build`
3. 宝塔面板 → Node项目 → 重启项目

## 📞 需要帮忙？

如果部署过程中遇到问题，按这个顺序排查：

1. 先看**报错信息**，复制到搜索引擎查
2. 检查**端口是否放行**（腾讯云防火墙 + 宝塔防火墙都要检查）
3. 检查**.env 配置**是否正确（特别是 NEXTAUTH_URL）
4. 查看**日志**：宝塔面板 → Node项目 → 点"日志"看报错
