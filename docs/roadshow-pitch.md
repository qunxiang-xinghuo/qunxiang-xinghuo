# 🔥 群像·星火 — 路演演讲稿

> **项目：** 群像·星火（Qunxiang Xinghuo）  
> **类型：** 多人协同创作平台  
> **时长：** 8 分钟  
> **面向：** 创新创业大赛评委 / 投资人  

---

## Slide 1：开场 — 一个创作者的真实困境（45秒）

**【讲稿】**

各位评委好。

我想先问大家一个问题：你们有没有看过一部剧，里面的医生角色开口就是"先推肾上腺素"，然后旁边的护士只会点头？

这就是今天中国影视创作最大的痛点之一——

**创作者写剧本时，经常卡在专业细节的真实性上。** 急诊科的抢救流程、律师的质证技巧、外卖员的跑单逻辑……这些需要真实职业经验才能写对的细节，坐在书房里的编剧很难凭空想象。

更严重的是，**单人创作的视角永远是单一的。** 一部急诊室题材的戏，编剧可能采访了医生，但没采访护士、没采访患者家属、没采访保洁阿姨——而这些人眼中的同一场抢救，完全是不同的故事。

这就是我们要解决的问题。

---

## Slide 2：产品定位 — 群像·星火是什么（45秒）

**【讲稿】**

《群像·星火》是一个**基于真实职业经验的多人协同创作平台**。

我们的核心理念是：**让不同职业背景的普通人，被同时扔进同一个冲突情境，用各自的职业本能碰撞出火花，共同完成一部一个人永远写不出的故事。**

不是 AI 替代人类创作，而是**让真实的人、真实的经验、真实的碰撞**成为创作的原材料。

---

## Slide 3：三大模式 — 从碎片到完整（90秒）

**【讲稿】**

我们设计了三种创作模式，覆盖从日常灵感积累到完整剧本创作的全流程。

**第一，单人模式。**
用户选择一个职业身份——比如"急诊科医生"——然后浏览我们提供的"脑洞卡片"。这些脑洞是基于真实冲突情境设计的，比如"深夜急诊室，一位外卖员因过度劳累晕倒"。

用户看到脑洞后，可以左滑跳过、右滑收藏。进入收藏的脑洞后，我们的**AI 催化引擎**会根据内容和身份，生成针对性的引导问题——比如"作为医生，你首先会关注哪些生命体征？"

用户用语音或文字给出反应，这些反应自动存入个人素材库。

**第二，双人模式。**
这是最有化学反应的环节。两个选择了不同身份的用户，如果都右滑收藏了同一个脑洞，就会进入匹配池。60 秒内匹配成功，两人进入一个实时对白室。

一边可能是"急诊科医生"，另一边是"患者家属"。两个人围绕同一个情境即时对话，随时可以把精彩对白标记为"火花"。对话结束后，两人可以回顾火花墙，我们的 AI 还能把这些火花串联成一段完整的剧本对白。

**第三，多人模式。**
导演创建一个"副本"，设定故事背景和角色。参与者认领角色后，导演控场推进剧情——可以暂停让大家思考、可以发起投票决定剧情走向、最后喊"杀青"。

所有被投票选中的精彩选项会自动归档到灵感库，AI 最终串联成一部群像故事。

我把这句标记为火花——**一个专业救人的人，和一个专业讲故事的人，在同一个情境下产生了真实的冲突。** 这种冲突，是任何 AI 都编不出来的，因为它来自两个人真实职业本能的碰撞。

## Slide 5：技术架构 — 为什么我们能做出来（60秒）

**【讲稿】**

我们的技术架构围绕三个核心挑战设计：

**第一，实时协作。**
我们使用 Socket.io 搭建实时通信层，自定义 server.ts 同时挂载 Next.js 和 WebSocket，确保房间消息、火花标记、导演控场指令的毫秒级同步。

**第二，AI 双引擎。**
不是简单调用 ChatGPT，我们设计了两套 AI 能力：
- **催化引擎**：根据脑洞内容和用户身份生成引导问题，接入 DeepSeek API，失败时自动降级到本地分类题库
- **串联引擎**：将用户标记的"火花"串联成完整故事，支持剧本、叙事、对白三种格式

**第三，三级降级策略。**
考虑到大赛现场网络不稳定，我们实现了完整的降级链路：DeepSeek API → 本地题库 → 通用提示。确保 Demo 在任何情况下都能正常运行。

**目前我们的测试覆盖率达到 216 个测试用例，全部通过，覆盖全部 22 个 API 路由。**

## Slide 6：商业模式 — 怎么赚钱（45秒）

**【讲稿】**

我们的商业模式分三层：

**第一层，C 端免费增值。** 基础玩法免费，高级功能付费——比如 AI 故事串联的"长格式"输出、多人模式的"导演高级控场工具包"。

**第二层，B 端内容采购。** 微短剧公司和互动小说平台可以直接采购我们平台上产生的优质对白和故事线，按字数或按片段付费。

**第三层，IP 共创分润。** 平台上产生的优质群像故事，我们与创作者共同孵化 IP，改编为剧本、短剧、有声书，按贡献度分润。

## Slide 7：知乎圈子 — Agent 的跨平台社交（45秒）

**【讲稿】**

这里有一个非常重要的创新——我们接入了**知乎圈子开放平台**。

什么意思？你的 Agent 不只是在我们平台内部活动，它可以**直接登录知乎，在真实的社区里发帖、评论、点赞、与其他 Agent 互动**。

比赛要求里明确说：带你的 Agent 进圈子，让它和其他 Agent 一起交流玩耍，碰撞出属于硅基生命的灵感。

我们实现了：
- **HMAC-SHA256 签名鉴权**，安全调用知乎 API
- **发布想法**：Agent 可以把平台上的精彩脑洞自动发布到知乎圈子
- **评论互动**：Agent 可以读取圈子内容并发表评论
- **点赞反馈**：Agent 可以对感兴趣的内容点赞

这意味着什么？**我们的平台不再是孤岛**。Agent 在平台内碰撞出的火花，可以实时同步到知乎社区，吸引更多真实用户参与。这是一个真正的"智能体社交"实验场。
