## 二、双人模式·身份选择流程

### 2.1 入口
- 首页点击【双人模式】→ 直接进入身份选择界面
- **不显示任何脑洞列表**

### 2.2 身份选择界面（复用DuoIdentityModal）
三种选项：
1. **知乎身份** - 使用已认证的职业身份
2. **AI随机生成** - 系统分配一个随机角色（急诊科医生、辩护律师等）
3. **自定义角色** - 用户输入自己想要的身份

### 2.3 匹配请求参数
```typescript
{
  brainholeId: undefined,  // 快速模式不指定脑洞
  identity: string,         // 选中的身份
  preferDifferent: true,
  timeoutMinutes: 1,
  mode: 'quick'             // 快速匹配模式
}
```

## 三、双人模式·匹配等待流程（核心）

### 3.1 页面元素
- 刘看山形象动画（上下浮动）
- 文案："刘看山正在为你寻找对撞人…"
- **60秒倒计时**，每秒更新，高度可见（进度条+数字）

### 3.2 状态机

```
[matching] --匹配成功--> [matched] --跳转--> /room/:id
    |
    | 60秒超时
    v
[timeout_1st] --选"是"--> [ai] --跳转--> /room/:id (AI房间)
    |
    | 选"否"
    v
[matching_2nd] --匹配成功--> [matched]
    |
    | 60秒超时
    v
[timeout_2nd] --选"是"--> [ai]
    |
    | 选"否"
    v
[exit] --跳转--> 首页
```

### 3.3 弹窗文案

**第1次超时弹窗**:
- 标题："当前暂无真人，是否与刘看山一起探讨？"
- 按钮1：【是，与刘看山对白】
- 按钮2：【否，继续等待】

**第2次超时弹窗**:
- 同上文案和按钮
- 选"否" → 退出匹配流程，返回首页

### 3.4 刘看山AI
- 调用 `POST /api/rooms/ai`
- 参数：`{ brainholeId?, identity }`
- 背后驱动：DeepSeek + 知乎直答API 融合体
- 随机角色进行回答互动
